# اتحادیه منچرز — Mini App UI v3

بازطراحی موبایلی بر اساس تصویر مرجع ارسالی کاربر.

## اجرا در Termux
```bash
cd ~/downloads/miniapp
python -m http.server 8080
```
سپس در مرورگر گوشی باز کنید:
`http://127.0.0.1:8080`

بازی‌های فعلی: منچرز، مارکرفت، تخت‌نرد پلاتو، حکم سوبرا.
آدرس واقعی بازی‌ها در `app.js` هنوز وارد نشده است.
